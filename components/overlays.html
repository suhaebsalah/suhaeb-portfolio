Case Study · 01

Adnan Electric - Business Management System

The Problem
The business needed a centralized system to manage projects, workers, payments, expenses, and reports instead of keeping operational information across different records.
What I Built
A private Laravel management system with an admin dashboard for projects, worker profiles, schedules, payments, expenses, search, filtering, reports, and protected admin routes.
Architecture
Built with Laravel MVC, Eloquent models, Blade components, Form Requests, validation, AJAX, and Fetch API interactions.
Stack
